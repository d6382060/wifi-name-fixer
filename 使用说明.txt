【Wi-Fi 名称显示修复助手 · 使用说明】

▊ 这个工具是干什么的？

如果你的电脑打开 WiFi 列表时，中文的 WiFi 名字全部变成了乱码
（比如显示成 "²âÊÔÍøÂç" 或 "������" 这种），
导致找不到自己家/公司的 WiFi，这个工具可以帮你：

  1. 找出乱码的原因（用大白话告诉你）；
  2. 把乱码 WiFi 的"真实中文名字"直接显示给你看——
     马上就能认出你要连的那个 WiFi；
  3. 给出安全的修复办法（能自动修的自动修，需要动手的
     一步一步教你，每一步都是 Windows 自带的正规设置）。

▊ 怎么用？（只需三步）

  第 1 步：双击打开 WiFiNameFixer.exe
  第 2 步：点击蓝色的大按钮「开始检测」，等 5～8 秒
  第 3 步：照着屏幕上的结论和提示做就行

▊ 常见问题

问：这个工具安全吗？会不会把电脑弄坏？
答：安全。检测过程只是"看一看"，不改动电脑任何设置。
    修复动作只有一个是自动的（重启 WiFi 系统服务，重启电脑
    也会有同样效果），其余都是教你在 Windows 自带的设置窗口
    里手动操作，随时可以原路改回去。
    工具不联网、不收集信息、不后台运行、不开机自启。

问：为什么修复时会弹出一个蓝色的确认框？
答：那是 Windows 自带的管理员授权确认（UAC），点「是」即可。
    只有重启系统服务时才需要，平时检测不需要。

问：工具说要"重启电脑"，必须重启吗？
答：如果原因是系统编码设置（工具会告诉你），改完设置必须
    重启一次才生效。不方便马上重启的话，可以先在工具的
    对照表里认出你要连的 WiFi（看"系统面板显示为"那一列），
    直接去系统 WiFi 列表里连它——乱码不影响连接和上网。

问：检测说"一切正常"，但我还是看到乱码？
答：按工具建议先点「一键安全修复」刷新一下；还不行就更新
    无线网卡驱动（工具里有步骤）；也可以点「保存诊断报告」，
    把桌面上的报告文件发给会修电脑的朋友。

问：双击后窗口打不开？
答：极少数老电脑缺少"WebView2 运行时"。工具会弹窗给出微软
    官方下载地址，装好后重新打开本工具即可。

▊ 给帮忙修电脑的朋友

  · 报告文件：桌面「WiFiNameFixer_诊断报告.txt」，包含
    ACP/OEMCP、Beta UTF-8 状态、系统区域、每个 SSID 的
    原始字节 HEX 与编码判定、网卡驱动信息。
  · 命令行自检：WiFiNameFixer.exe --selftest 报告.txt
  · 乱码根因通常是二选一：勾了"Beta: Unicode UTF-8 全球
    语言支持"（ACP=65001），或"非 Unicode 程序的语言"不是
    简体中文（ACP≠936）。修复入口：intl.cpl → 管理 →
    更改系统区域设置，改完重启。
